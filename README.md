# 📊 CSM Health Score Dashboard

A production-grade **Customer Success Manager portfolio dashboard** built to demonstrate real-world CSM skills including account health scoring, churn risk identification, adoption tracking, renewal pipeline management, and QBR workflows.

**Live Demo:** [View Dashboard](https://kararkazmi238-bot.github.io/csm-health-dashboard)

---

## 🎯 What This Demonstrates

This project showcases skills directly relevant to Customer Success Manager, Onboarding Specialist, and Customer Operations roles:

| Skill | How It's Demonstrated |
|---|---|
| **Portfolio Management** | 50-account simulated portfolio with health scoring |
| **Churn Prevention** | Risk flags, early warning indicators, action items |
| **Adoption Tracking** | Feature adoption rates with visual progress bars |
| **Renewal Pipeline** | Renewal date tracking with urgency classification |
| **QBR Management** | Business review status tracking per account |
| **Health Scoring** | Composite scores driving Healthy / At-Risk / Critical classification |
| **Expansion Identification** | Upsell and expansion opportunity flagging |
| **Data Visualization** | Donut chart, bar charts, funnel analysis |

## 📈 Dashboard Features

### Account Health Overview
- Summary KPI cards: Healthy / At-Risk / Critical counts + Average Health Score
- Portfolio stats strip: ARR, renewals, NPS, adoption rate, QBR completion, expansion opps

### Account Portfolio Table
- Filterable by health status
- Health score pills with live pulse animation on critical accounts
- Adoption rate mini-bars
- Renewal date urgency badges
- Recommended CSM action per account

### Account Detail Panel
- Click any row to open a slide-in detail panel
- Shows: Health score, adoption rate, renewal date, QBR status
- CSM notes, activity timeline, and recommended next action

### Portfolio Analytics
- Donut chart: Health distribution breakdown
- Horizontal bar chart: Adoption rates for top accounts by ARR
- Onboarding funnel: New customer pipeline stages

### Live Activity Feed
- Recent CSM activities: renewals, health checks, risk flags, expansions
